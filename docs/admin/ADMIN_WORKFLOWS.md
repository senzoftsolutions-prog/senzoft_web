# Admin workflows

## Careers

1. Create a draft job, complete the job and SEO fields, then publish it.
2. Review applications using search, job/status filters, and server pagination.
3. Open an application to inspect its immutable status history and move it through the permitted transition actions with a reason.
4. Manage interview schedules, candidate documents, background verification, offers, and joining records from their modules.
5. Close or archive jobs when recruitment ends. These actions are audit logged.

## Blog

1. Create a draft with title, slug, excerpt, sanitized article content, featured-image metadata, and SEO fields.
2. Save it before scheduling. A schedule date must be in the future.
3. Publish immediately or archive from the list. Scheduled posts become publicly eligible only after their publish timestamp and published status are valid.

## Administration

Admins can change roles, activate/deactivate users, and inspect the append-only audit list. Use the audit module to trace the actor, action, entity, timestamp, and metadata for sensitive operations.
