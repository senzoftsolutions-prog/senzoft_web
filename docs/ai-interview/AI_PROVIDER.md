# AI and speech providers

Set `AI_PROVIDER=mock` for the implemented deterministic provider. It builds bounded questions from job title/skills and candidate context, evaluates using deterministic text characteristics, optionally asks a clarification, and produces a structured human-review summary.

The scores are test/development decision-support data, not hiring decisions. A production model adapter must implement `AIInterviewProvider`, validate structured output, enforce timeouts, and keep credentials server-side. The current phase does not require a paid model.

`BrowserTranscriptProvider` accepts text generated by supported browser speech recognition or typed by the candidate. Unsupported browsers retain a complete typed-answer path. No audio is transmitted.
