# AI and speech providers

Set `AI_PROVIDER=native` for the Senzoft-owned deterministic provider. It builds bounded questions from job title/skills and candidate context, evaluates using deterministic text characteristics, optionally asks a clarification, and produces a structured human-review summary.

The scores are decision-support data, not hiring decisions. Set `AI_PROVIDER=ollama` to use a private model running on the backend host. Structured output is validated and the native provider is used automatically when the local model is unavailable.

`BrowserTranscriptProvider` accepts text generated by supported browser speech recognition or typed by the candidate. Unsupported browsers retain a complete typed-answer path. No audio is transmitted.
